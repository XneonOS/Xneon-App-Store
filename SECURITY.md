# Security Policy

## Supported Versions

Only version **1.1.0** of **Xneon App Store** is currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.1.0   | :white_check_mark: |
| < 1.1.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in **Xneon App Store** (such as an issue with binary downloads, checksum verification, or GitHub release handling), please **do not** open a public issue.

1. Use GitHub's **Private Vulnerability Reporting** feature under the repository's **Security** tab (or contact the maintainers privately).
2. Include the affected version (`1.1.0`), steps to reproduce, and any relevant logs or proof-of-concept details.
3. You can expect an initial acknowledgment within a few days while the issue is investigated and patched.
